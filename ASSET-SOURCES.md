# VANTA DRIVE — Asset Sources

Vehicle imagery is concept artwork for a portfolio demo. It does not represent a verified rental inventory or manufacturer endorsement.

## Supplied concept images

The following files were supplied with the project and are retained unchanged under `public/images`:

- Vehicles: `porsche-911.webp`, `mercedes-amg-gt.webp`, `bmw-i7.webp`, `range-rover-sport.webp`, `audi-rs6.webp`, `mercedes-vclass.webp`, `volvo-xc90.webp`, `tesla-model-s.webp`.
- Services: `airport-delivery.webp`, `corporate-fleet.webp`, `chauffeur-service.webp`, `hero-vanta.webp`, `location-istanbul.webp`, `vanta-garage.webp`.

Independent provenance and license documentation for these supplied images is not included.

### Model details

- The BMW 760e concept uses a BMW 750e G70 body reference with edited badging; it is not a verified 760e photograph.
- The BMW M8 artwork depicts the Gran Coupé body.
- Exact model year, badges and equipment are not certified by these concept images.
